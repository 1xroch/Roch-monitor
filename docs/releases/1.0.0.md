Roch Monitor 1.0.0 is the first release: live hardware sensors in one window, each with its current, minimum, maximum and average, in the style of HWiNFO and HWMonitor. It runs on Windows and Linux, and it is read-only: it changes no setting.

## What it shows

- **CPU:** per-core temperatures, clocks and VIDs and per-thread effective clocks (Intel, through PawnIO); the SMU's PM table on AMD Ryzen (Tctl, per-core clocks and voltages, SoC and VDDG rails, PPT/TDC/EDC against their limits, FCLK and UCLK); usage per thread, labelled P-core and E-core.
- **Memory controller and DIMMs:** data rate, MCLK and UCLK, VCCSA and VDDQ TX from MCHBAR; each DDR5 module's SPD hub temperature and its PMIC's measured VDD, VDDQ, VPP and power.
- **Motherboard:** temperatures, voltages, fans and duty from the Super I/O (Nuvoton and ITE), and the VRM temperature on ASUS boards.
- **GPUs:** temperatures, voltages, every clock, load, power, fans, VRAM and the PCIe link, from Roch GPU's backends (NVIDIA, AMD and Intel Arc on Windows; AMD through the amdgpu driver on Linux).
- **Drives and network:** temperatures, activity and transfer rates.
- **Windows hardware errors:** WHEA events since boot.

Click a sensor to graph it, log every visible sensor to CSV, save a text report, or put readings in the Windows tray as icons of their own. `RochMonitor --dump` prints the whole table in a terminal.

## Linux

- Runs as your normal user on Wayland or X11. Readings come from the kernel's hwmon drivers, `/proc`, powercap and Roch GPU's `amdgpu` backend.
- On the **Gigabyte Z890 AORUS TACHYON ICE**, **Voltages → Read board voltages** reads Vcore, VCCSA, VNNAON, VDD2, VCCIO and the ATX supply rails from the board's ITE chips through a helper that asks for your password (pkexec) when you start it.
- Per-core VIDs, DDR5 PMIC readings, WHEA and the tray are Windows-only for now.

## Install

- **Windows:** download **RochMonitor.exe** below and run it. Install [PawnIO](https://pawnio.eu) for the readings that need a kernel driver (CPU registers, Super I/O, SMBus); without it, CPU usage and clocks, GPUs, drives and network still work.
- **Linux (x86-64, glibc 2.35 or newer):** download **RochMonitor-1.0.0-linux-x86_64.tar.gz**, unpack it and run `./install.sh`. That installs `rochmonitor` to `~/.local/bin` and adds Roch Monitor to your launcher, without root.

`SHA256SUMS.txt` has the checksums of both.

## What has been tested

The Windows and Linux builds passed CI on this commit (format, lint, tests and a `--dump` smoke test on each). Windows was checked on an MSI PRO Z790-P WIFI DDR4 with a Core i9-14900KF and an RTX 5060 Ti, where readings from separate sensors agree with each other (MCHBAR VCCSA against the Super I/O's CPU SA, each core's VID just under the measured Vcore). Linux was run on a Gigabyte Z890 AORUS TACHYON ICE with a Core Ultra 7 270K Plus and two RX 7900 XTs: CPU, DIMM, both GPUs (including fans, PCIe link and VRAM), NVMe and network readings all answered. Other boards' Super I/O maps come from Roch Viewer and have not all been re-run since being ported.
