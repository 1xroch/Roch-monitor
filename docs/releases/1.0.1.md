Roch Monitor 1.0.1 stops asking for your password on Linux when you read the board voltages.

## Changes

- **Linux: no password for the board voltages.** `sudo ~/.local/bin/rochmonitor setup` installs a root-owned copy at `/usr/local/bin/rochmonitor` and a polkit rule that lets you, and only you, start exactly that copy as the board-voltage collector from your own desktop session. The collector only reads the board's Super I/O; it changes no setting. A rule naming the copy in `~/.local/bin` would hand out root, since anything running as you can replace that file, so the copy lives where only root can change it.
- Roch Monitor uses the installed copy only while it is byte for byte the running build, so after an update it asks again until you re-run setup. `rochmonitor setup --status` reports the state, `rochmonitor setup --show` lists what it would change, and `sudo rochmonitor setup --undo` removes it.

## Install

- **Windows:** download **RochMonitor.exe** below and run it. Install [PawnIO](https://pawnio.eu) for the readings that need a kernel driver (CPU registers, Super I/O, SMBus); without it, CPU usage and clocks, GPUs, drives and network still work.
- **Linux (x86-64, glibc 2.35 or newer):** download **RochMonitor-1.0.1-linux-x86_64.tar.gz**, unpack it and run `./install.sh`. That installs `rochmonitor` to `~/.local/bin` and adds Roch Monitor to your launcher, without root. Then, optionally, `sudo ~/.local/bin/rochmonitor setup`.

`SHA256SUMS.txt` has the checksums of both.

## What has been tested

The Windows and Linux builds passed CI on this commit (format, lint, tests and a `--dump` smoke test on each). On the Gigabyte Z890 AORUS TACHYON ICE (Linux), after `setup`, **Read board voltages** started its collector with no prompt and read Vcore, VCCSA and VNNAON. Windows is unchanged from 1.0.0 apart from the version number.
